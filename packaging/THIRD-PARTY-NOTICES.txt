Bundled runtime components
==========================

The SDL2 release packages may include runtime libraries from:

- SDL 2, under the zlib license: https://www.libsdl.org/
- LZO 2, under GPL-2.0-or-later: https://www.oberhumer.com/opensource/lzo/
- LLVM compiler-rt and libc++, under Apache-2.0 WITH LLVM-exception:
  https://llvm.org/
- GCC runtime libraries on Linux, under GPL-3.0-or-later WITH
  GCC-exception-3.1: https://gcc.gnu.org/
- YMFM, under the BSD-3-Clause license:
  https://github.com/aaronsgiles/ymfm
- Slint 1.18.1, under GPL-3.0-only for this GPLv3 application:
  https://github.com/slint-ui/slint/tree/v1.18.1
- Native File Dialog Extended 1.3.0, under the zlib license:
  https://github.com/btzy/nativefiledialog-extended
- NSIS Windows installer runtime, under the zlib/libpng license, with its
  LZMA compressor under CPL-1.0 and the NSIS linking exception:
  https://nsis.sourceforge.io/Docs/AppendixI.html

The exact set is platform-dependent. System libraries supplied by Windows,
macOS, or the Linux distribution are not copied into these packages.

Spanish translation
===================

Base-game text, translated artwork and accent glyphs come from L@Zar0 and darkpadawan's
Wing Commander II Spanish translation, version 1.1 (2021).
The upstream notice declares GPL v3.0 and an additional no-charge term.
Its complete terms and credits accompany the catalog in
translations/Spanish-README.txt (inside Contents/Resources in the macOS app).
Editable translation sources and import provenance are included in this
release's source tag under translations/.

Source archive:
https://www.mediafire.com/file/pvkt604rsnrr82f/WC2_OPS1y2_V1.1.zip/file

Polish translation
==================

Text, translated menu artwork and Polish letter glyphs for the base game and
both Special Operations come from paxiu1984's Wing Commander II Polish patch,
version 1.4 (2026), which builds on L@Zar0 and darkpadawan's Spanish
translation. Its authors release it under GPL v3.0 with an additional
no-charge term, as for the Spanish translation; the game's rights belong to
Electronic Arts. The upstream credits and license accompany the catalog in
translations/Polish-LICENSE.txt, and the patch's README in
translations/Polish-README.txt (inside Contents/Resources in the macOS app).
Editable translation sources and import provenance are included in this
release's source tag under translations/.

Credits and license:
https://steamcommunity.com/sharedfiles/filedetails/?id=3834561725
Source archive: WC2_Spolszczenie_PL_v1.1_latka.zip
SHA-256 1137ab167fd1c80bf5ceb74a94cb9b040cac2a1dfd5a17697a1be507aa8a61d5
